# API reference

Interactive documentation is generated by FastAPI:

- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`
- OpenAPI JSON: `http://localhost:8000/api/v1/openapi.json`

To try authenticated endpoints in Swagger, call `POST /api/v1/auth/token` (username = email), then click
**Authorize** and paste the `access_token`.

## Conventions

- Base path: `/api/v1`. JSON request and response bodies, except resume upload (`multipart/form-data`).
- Lists return `{ "items": [...], "total": n, "page": 1, "page_size": 20 }`; `page_size` max 100.
- Errors always return `{ "error": { "code": "...", "message": "...", "details": ... } }`.
- Validation errors (422) list `details: [{ "loc": [...], "msg": "..." }]` without echoing input.
- Another user's resource is reported as **404**, never 403, so IDs cannot be probed.
- Cookie-authenticated `POST/PATCH/PUT/DELETE` requests must send `X-Requested-With: <any value>`.

| Status | Typical codes |
|---|---|
| 400 | `last_version`, `invalid_reset_token`, `invalid_comparison` |
| 401 | `not_authenticated`, `session_expired`, `invalid_credentials` |
| 403 | `csrf_failed`, `ai_consent_required` |
| 404 | `not_found` |
| 409 | `email_taken`, `duplicate_resume`, `duplicate_job` |
| 413 | `file_too_large` |
| 422 | `validation_error`, `unsupported_file_type`, `file_type_mismatch`, `no_text_found`, `encrypted_document`, `too_many_pages`, `unresolved_placeholders` |
| 429 | `rate_limited` (with `Retry-After`) |
| 503 | `ai_unavailable`, `ai_timeout`, `ai_rate_limited`, `ai_invalid_response`, `database_error` |

## Endpoints

### Authentication
| Method | Path | Description |
|---|---|---|
| POST | `/auth/register` | Create an account; sets the session cookie |
| POST | `/auth/login` | Sign in; sets the session cookie |
| POST | `/auth/token` | OAuth2 password flow; returns a bearer token |
| POST | `/auth/logout` | Clear the session cookie |
| GET | `/auth/me` | Current user |
| POST | `/auth/password-reset/request` | Email a reset link (always 202) |
| POST | `/auth/password-reset/confirm` | Set a new password with a reset token |

### User profile
| Method | Path | Description |
|---|---|---|
| PATCH | `/users/me` | Update name and AI processing consent |
| POST | `/users/me/password` | Change password (invalidates other sessions) |
| DELETE | `/users/me` | Delete account and all data (body: `{ "password" }`) |
| GET | `/users/ai-config` | Active AI provider and whether consent is required |

### Resumes
| Method | Path | Description |
|---|---|---|
| POST | `/resumes` | Upload PDF/DOCX (`file`, optional `title`); extracts and parses locally |
| GET | `/resumes?q=&page=` | List resumes |
| GET / PATCH / DELETE | `/resumes/{id}` | Detail, rename, delete (with file and versions) |
| GET | `/resumes/{id}/file` | Download the original file |
| GET | `/resumes/{id}/text` | Extracted raw text |
| POST | `/resumes/{id}/reparse` | Parse the original text into a new version |
| POST | `/resumes/{id}/versions` | Save a new version (`label`, `source`, `data`) |
| GET | `/resumes/{id}/versions/compare?base=&target=` | Section-by-section diff |
| GET / PATCH / DELETE | `/resumes/{id}/versions/{vid}` | Version detail, update, delete |
| GET | `/resumes/{id}/versions/{vid}/export.pdf` | Export as PDF |
| GET | `/resumes/{id}/versions/{vid}/feedback` | Feedback reports for a version |

### Job descriptions
| Method | Path | Description |
|---|---|---|
| POST | `/jobs` | Save a job; requirements are extracted |
| GET | `/jobs?q=&page=` | List jobs with analysis count and best score |
| GET / PATCH / DELETE | `/jobs/{id}` | Detail, update (description or skill lists), delete |
| POST | `/jobs/{id}/reset-skills` | Discard manual skill edits and re-extract |

### Matching and history
| Method | Path | Description |
|---|---|---|
| POST | `/analyses` | Match one resume version against 1–10 jobs (`include_ai_insights`) |
| GET | `/analyses` | Filter: `q`, `resume_id`, `resume_version_id`, `job_id`, `min_score`, `max_score`, `sort` |
| GET | `/analyses/compare?ids=a&ids=b` | 2–4 analyses side by side |
| GET / DELETE | `/analyses/{id}` | Full result, delete |
| POST | `/analyses/{id}/insights` | Retry or regenerate AI insights |

### AI coaching
| Method | Path | Description |
|---|---|---|
| POST | `/feedback` | Resume feedback for a version, optionally tailored to a job |
| GET / DELETE | `/feedback/{id}` | Report detail, delete |
| POST | `/interview-prep` | Practice questions for a version and job |
| GET | `/interview-prep` | List |
| GET / DELETE | `/interview-prep/{id}` | Detail, delete |

### Dashboard
| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Counts, recent analyses and versions, score trend, recurring skill gaps |
| GET | `/health` | Liveness and database connectivity (outside `/api/v1`) |
